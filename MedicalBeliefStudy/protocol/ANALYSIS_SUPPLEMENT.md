# 扩展分析与附加读出协议

此补充在扩展观察尚未汇总、读出拟合及名称评分运行前确定，不改变已经冻结的病例和观察输入。

1. 岭回归读出额外加入病例块打乱的训练目标对照；每个病例的三个阶段作为一组打乱，使用真实读出在开发集选定的alpha。测试集仍为独立60例。
2. 为检验答案代码依赖，对72个病例三种证据顺序的终点进行疾病名称序列评分。去除字母代码，要求输出六个规范疾病名之一；对完整名称及结束词元进行teacher-forcing，保存每词元log概率和完整序列log概率。完整序列概率在六个规范名称中归一化为主要名称支持；每词元平均log概率是长度敏感性分析，不称为严格序列概率。
3. 名称评分与代码评分使用不同输出任务，二者一致支持稳健性，二者不一致则报告测量依赖；不选择更接近标签的指标作为事后主指标。
4. 统计以新增60个病例为主，疾病等权。病例bootstrap同时携带其所有轮次、映射与顺序，不把前缀当成独立患者。疾病组、全部事件表和探索12例另外保存。
5. 保存每个相邻轮的疾病分布变化、层首选变动、层间分歧、证据问题ID、模块变化和方向对照，提供完整个案附录。主文依据总体率及配对差异形成结论。
