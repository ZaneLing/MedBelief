# 阶段13—16：逐轮更新、固定问卷与疾病方向干预

冻结于本轮新增模型观测之前。保留已有结果，所有新增原始记录写入 `runs/belief_v2`。

## 主线与有限交付

1. 新病例复现：从 DDxPlus test split 按固定哈希选24病种各5例，共120例。排除与既有372例重复的完整证据集合（忽略年龄性别）；24例按独立哈希选定追踪全部轮次。新病例与旧120例属于不同数据划分，但仍属于同一个模拟数据生成来源，不称外部临床验证。
2. 固定问卷：公开证据字典的223个字段对所有病例相同，按字段编号排序，未知保持未知。逐轮仅揭示来源中已有答案。旧120例终点用于训练读出器，新120例用于独立测试，24例保留全轨迹。对相同病例同时运行原追加式提示，比较呈现条件。
3. 诊断方向因果使用：仅用旧120例终点训练线性读出器；新24例固定中间轮进行干预。预定层21/28，隐藏状态增量范数为原状态范数的5%，敏感性为2%。目标为来源标签，竞争病为未干预模型在24类中的最高非目标病；目标标签仅用于离线干预定义和评估，不进入自然提示。方向为两类读出权重之差，另设反向、同范数随机方向和零干预。
4. 汇总：先完成观测、读出、干预和数值验证，再更新论文主线、证据表、完整论文草稿与待验证边界。模型规模与另一临床来源未完成时如实记录。

## 测量与对照

- 固定49病全名称序列评分，保留未归一化对数概率、逐token分数、规范字符串总质量、自由续写。
- 每轮保存28层的进入状态、attention增量、MLP增量、离层状态及诊断位置注意力分配；参数始终冻结。
- 固定问卷不会消除“哪些答案已知”的信息。追加 presence-only 条件：已知位置只写 `Recorded; value withheld`，其余未知。问题列表、答案记录模式与具体值分开讨论。全部223个问题相同的 questions-only 基线无区分能力是构造性质，不是实验发现。
- 不将源数据未记录的二元项改为 No，不添加真实患者事实；没有每轮医学标准后验。
- 外部线性读出L2归一化+训练均值中心化，ridge alpha=0.1，.01与1为敏感性。旧120例训练，新120例测试，不在新病例重新调参。给出第7/14/21/28层及完整层曲线。24类读出只与限制到同24类的原生排名直接比较；49类输出独立报告。
- 逐轮“跳变”主描述：任一疾病支持单次绝对变化≥0.50；.10/.25敏感性。首选改变与大幅分数变化分别计数。内部读出是分数/排名，不擅自变为校准概率。
- 干预分两位置：仅诊断锚点；锚点及所有后续教师强制病名位置。最后层锚点干预理论上只能改变第一个输出token，不影响缓存中的后续状态，故必须分解首token与后续token效应。所有干预报告完整49病选择性，不能只用目标概率增加证明疾病概念因果使用。
- 目标与同首token其他病的相对完整序列分数作为词汇混淆控制；无同首token竞争者的病例单列。病名续写全位置干预可能直接改变词汇生成，仍须内容/位置控制，不直接等同于自然医学信念。
- 零干预与原前向的分布JS<1e-5且首选一致，未通过者不进入主要因果汇总并完整保留。
- 病例为统计单位；逐轮先病例内平均再bootstrap。固定随机种子；测试集结果只报告不用于选择层位和剂量。若失败，追加实验另写带时间顺序的协议，不覆盖失败结果。
