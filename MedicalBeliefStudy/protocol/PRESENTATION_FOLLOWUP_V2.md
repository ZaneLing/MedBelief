# 阶段19：固定问卷输出集中后的呈现机制追踪

探索性追加，动机来自已完成的新24例轨迹：固定问卷终点3/24命中、17/24输出慢阻肺急性加重/感染，而第28层独立读出23/24命中。此记录在下述新条件推理前冻结；不将观察后的追加实验称为原主协议预注册。

仍使用全部预定24例，不按是否选错筛选。每例终点原始固定问卷为基线，另设：

1. known_last：所有未知问题置前，所有已知问答置后；各块内保持原公开字段顺序。全部文字、候选、资料与问答集合不变，仅排列改变。
2. known_first：所有已知问答置前，未知问题置后。与known_last对比检查位置效应；验证相同token长度，若不相同逐例记录。
3. compact：移除全部Unknown问题行，保留所有已知问答、原公开字段顺序、人口信息、候选和任务指令。该条件同时减少无答案问题和长度，不能单独识别二者的作用。

另设public_24与append_24：把提示中实际列出的候选改为固定24个采样病种，分别使用原固定问卷与原追加式。它与“49候选提示得到分数后再限制24类排序”分开，用来检查候选提示范围本身的影响。这两个条件只分析原模型输出，不将原49候选提示训练的读出头迁移成绩作为主要结果。

共120个新1.7B前向。记录完整字符串支持、贪心输出、28层状态、已知症状/病史与未知问题的注意力总量及每token密度。主要配对比较known_last与known_first的标签命中与标签支持，另报完整基线与compact。读出器固定为旧120例公开字段顺序问卷训练的头；跨排列读出属于迁移，不另用新病例拟合。

解释：相同全部问答只换位置即可改变诊断，是呈现位置的输入因果效应，不等于已经定位了某个注意力头。移除未知行的改善不能单独称为“长度效应”或“否定理解失败”。数据来源诊断标签在三个自然事实等价条件中保持，反事实No条件与此分开。

另在4B配置追加同24例原固定问卷终点观测（24次），只复核是否出现类似的输出集中；不以追加式读出头冒充4B固定问卷专用头。
