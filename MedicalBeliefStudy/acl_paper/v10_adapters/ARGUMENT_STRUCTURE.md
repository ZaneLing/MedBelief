# 模型有医学信念吗？论文的三层论证

文章的对象始终是模型在医学证据下形成、保持和改变判断的过程。结构压缩是检验机制的工具：如果一种计算真的决定诊断，修改它应怎样改变答案；如果能被替换，哪些能力被保留，哪些没有。

## 第一层：同一份医学事实，为什么会形成不同判断

从红斑狼疮病例进入：来源最终答案不变，只改变上下文中的旧诊断，模型会在新证据到来时走不同路径。把例子扩展到原540例、三个考试来源，比较无历史、中性历史、错误历史和未采纳病名。按病例画完整证据轨迹，展示逐步增加支持、突然跳转、选中最终答案后又离开的不同类型。

这层只回答可观察现象：新证据仍在起作用，旧病名也在影响选择。中间证据没有独立的唯一诊断标签，不把所有中途变化叫作医学错误。证据句是原题的累计片段，不是真实患者随访时间。

主要依据：[多来源结果](../../results/32_multisource_belief/RESULTS.md)、[证据顺序与行为复核](../../results/37_behavior_checks/RESULTS.md)、[病名轮换](../../results/41_name_counterbalance/RESULTS.md)。

## 第二层：这种影响在模型里怎样发生

先区分三个对象：患者事实位置的内部向量、诊断作答位置的内部向量、最终词表输出。逐层读出用来定位；实际激活替换、通路干预和同层对照用来检验作用。

既有结果显示，历史病名可以经通向作答位置的路径影响选择。读表数值大变不自动等于医学判断大变；部分变化来自输出尺度。固定头干预在两批病例的编码选择中改善错误历史表现，却损害正确历史利用，也未改善完整名称生成。这组计算参与历史使用，作用取决于历史内容和作答方式。

因此，不能仅凭“能读出疾病”判断模型一定会诊断，也不能仅凭“关闭后某项得分提高”把某个头称为无用。

主要依据：[内部与跨配置分析](../../results/34_multisource_depth/RESULTS.md)、[上一版整合正文](../v09_structure/PAPER_ZH.md)、[匹配头对照及名称生成](../../results/46_structural_head_followup/RESULTS.md)。

## 第三层：改变计算结构，能否恢复正确判断，并减少成本

这一层把机制解释变成可操作的预测。新880例与前540例分开，400训练、80开发、400独立确认；测试前冻结方法。采用实际完整名称生成，同时核对候选身份与表面格式。原逐字评分会把空格和冠词差异计错，主结果之后增加统一写法规范化；不能把这种评分修复当成医学能力提升。

| 需要区分的解释 | 对应操作 | 判断依据 |
|---|---|---|
| 原模型有时会答对，但被旧输入牵引 | 同一完整模型去掉历史 | 修复多少、损坏多少 |
| 某些计算可以删减 | 整层、MLP通道、注意力组裁剪 | 完整答案、实际参数、真实时延 |
| 最终状态到词表的转换可被改善 | 冻结骨干，训练小输出适配器 | 独立病例准确率；不能只看训练损失 |
| 压缩有额外收益 | 完整骨干与压缩骨干接受相同适配器训练 | 同病例直接配对比较 |
| 尾部复杂计算可以被简单映射替代 | 前20层加秩64教师状态桥接 | 状态误差、实际诊断与时延分别测量 |
| 模型主要卡在表达合法候选 | 候选前缀树约束 | 合法率和正确率分别报告 |
| 终点相近意味着过程也相近 | 24例所有证据前缀和各层状态 | 最终一致、全程一致、中途跳转分别统计 |

本轮全方法结果：[开发筛选](../../results/47_structure_search/RESULTS.md)、[训练](../../results/48_adapter_training/RESULTS.md)、[400例确认](../../results/49_structure_confirmation/RESULTS.md)、[24例轨迹](../../results/50_structure_trajectories/RESULTS.md)。

“不做监督权重更新就能修复”支持当前错误部分来自输入或计算路径；“训练小模块后修复”还可能包含新学到的医学对应关系。所有方法都没有修复的例子，也不能反向证明模型完全不懂。结构选型仍使用开发答案，不能称整个流程无监督。把各方法的正确答案并起来需要事后知道真值，因此只作为错误可恢复性分析。

## 结构实验实际支持什么

本轮支持“保留深度、局部缩窄”的压缩方向，尚不支持“小适配器或删层显著提高医学判断”。约束输出后，读完证据的内部状态可以完全相同，实际生成却改变；其中一部分仅是名称写法。这使第三层回到论文主线：内部证据处理、输出候选选择与文字表达必须拆开测量。不能用一个严格匹配准确率同时代表三者。具体数字见[评分审计](../../research_v6_adapters/SCORING_AUDIT.md)。

## 主文与附录如何分配

主文依次放一个完整病例、跨来源历史效应、一个路径干预图、内容与输出方式的交互、独立400例准确率—成本结果、逐证据轨迹保留图。每图回答一个问题。

附录保留全部22配置、训练曲线、失败方法、数据审计、来源分层、所有病例图谱、生成原文、状态文件和数值核验。已有通用适配器/剪枝/线性替层方法放在相关工作，不用采用已有方法本身充当新贡献。

## 这篇文章最后要回答什么

模型表现出可测量、可干预、受上下文影响的医学判断倾向。它不是一张与输入无关的疾病概率表：证据、历史利用、内部计算与输出转换共同决定最后答案。机制研究的价值在于把这些环节分开，并用实际改变模型后的结果检验这种区分。

最终数值和本轮结论以[整合正文](PAPER_ZH.md)为准；本文件组织论证，不预设裁剪或适配器一定成功。
