# 本轮方法来源与实现范围

这些方法用于检验医学判断如何被结构、训练与输出接口影响，不将采用既有压缩或适配技术本身当作论文创新。

| 方法脉络 | 已有工作 | 本轮实际实现 |
|---|---|---|
| 残差瓶颈适配器 | [Houlsby等，ICML 2019](https://proceedings.mlr.press/v97/houlsby19a.html)研究在冻结网络中加入小适配器实现迁移 | 本轮在最终归一化之后、原词表输出头之前，加入2048→16/64→2048的tanh残差计算；没有复现论文的全部插入位置 |
| 低秩参数更新 | [LoRA](https://arxiv.org/abs/2106.09685)通过低秩更新适配大模型 | 本轮瓶颈模块是单独的非线性输出适配器，不将它称为标准LoRA复现 |
| 逐维激活缩放 | [IA³ / T-Few](https://arxiv.org/abs/2205.05638)使用少量可学习向量调节激活 | 本轮做输出状态逐维缩放和平移，4096个参数；位置和目标不同于原IA³ |
| 结构剪枝与修复 | [LLM-Pruner](https://arxiv.org/abs/2305.11627)研究耦合结构的删减与恢复 | 本轮实际切除门控MLP的成组通道，或同步删去Q/K/V/O对应的KV头组；重要性用训练病例激活与投影范数估计，不冒充其梯度算法 |
| 尾层线性替换 | [ReplaceMe](https://arxiv.org/abs/2505.02819)已有用线性操作替换Transformer层的工作 | 本轮学习第20层至第28层的秩64桥接，比较拟合状态、完整候选生成和推理成本，不宣称首次提出线性替层 |
| 层间对比解码 | [DoLa](https://arxiv.org/abs/2309.03883)通过不同层的分布对比改善生成事实性 | 本轮为固定第21层的静态变体，两档对比强度与0.1相对合理性过滤；没有实现原方法的动态选层，也没有参数压缩 |

候选前缀树约束只允许模型生成已有候选字符串，它是输出约束对照。它可能修复格式与拼写，也可能帮助在原候选中选择，但不新增医学监督。完整名称生成的正确性、合法率和参数/速度必须同时报告。

最有辨识力的实验是同一批病例上的比较：不训练的结构改变能修复什么；同等小模块训练下，保留完整结构和压缩结构有何差异；内部状态拟合得更近，是否真的改善完整诊断。已有方法作为工具，医学证据与错误恢复关系作为研究对象。
