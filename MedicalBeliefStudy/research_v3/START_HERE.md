# 先读这一页：医学信念这篇文章现在讲什么？

> 本页为v0.6历史解释。2026-11-19已进行[研究重构与证据审计](../acl_paper/v07_reframing/START_HERE.md)：保留下列观测值，但不再将“内部可读”“末层评分可干预”直接解释为完整的医学信念机制。

**模型内部能保留疾病相关信息，但最后说出的诊断，不一定把这些信息用好。我们现在追踪的是这中间的整个过程。**

## 已经做完多少

新增240个模拟患者，覆盖24病、6组疾病；另有87道原始医学考试诊断题。159条完整证据轨迹、1173次新增证据，全层状态与注意力都有记录。又在相同患者上做4B配置复核，并完成历史、顺序、删证据和内部干预。总计4832个观测/干预条件，全部完成核验，API费用0美元。

## 最关键的结果

1. **内部读得出，答案未必跟得上。** 同样24种病，1.7B自己选对105/240，从最后一层读出194/240；4B为159/240与226/240。
2. **新证据确实改变内部，而且后层变化更贴近答案。** 第14层已有162/240的疾病信息可读，但更新与输出几乎不相关；第28层相关升至0.573。信息“在那里”和信息“被当前答案采用”是两个问题。
3. **以前说过什么，会影响内部和答案。** 24例完整病例，正/误历史下命中为23/24与2/24，错误历史使内部来源病排名平均后退3.08位。外部87道题加入错误旧诊断后，命中由45题降至30题。
4. **我们直接动了实际发生的内部更新。** 第28层的疾病方向分量在两批独立患者中都表现出对原生诊断分差的特异作用。 第28层目标移除改变首选的病例为首批1/24、复核1/48；改变分数和改变最终诊断分别统计。

## 文章按这六层往上走

**判断怎样长出来 → 里面有什么疾病信息 → 新证据改了哪些计算 → 旧判断和背景怎样影响它 → 删除内部变化能否改变输出 → 跨病例来源与模型配置是否还成立。**

每一层都回答上一层留下的问题。开头先用一题骨关节炎原题解释诊断转向，再用心肌梗死/HIV模拟病例打开内部测量；正文用全部患者给结论，所有成功、失败、回来和转错的路径都保留。

另外一个值得保留的结果：明确标注“既往史/当前表现”的72例解释检验中，明确标注既往史与当前表现，没有带来明确的总体诊断改善。 这使我们能够检验开头病例引出的解释，而不是见到一个例子就给所有病例套上同一种机制。

简单分类器在新患者上也很准，甚至只看问了什么就能命中235/240。这说明模拟数据的记录方式带有强线索；它帮助解释内部读出，不能单凭这一点宣布找到真实诊断的替代方法。
