# 轻量诊断模型：查重、五个新增数据集与跨数据集检验

2026-11-20。接续[DDxPlus 目录审计](../23_ddx_generator_audit/RESULTS.md)。本轮实际下载、训练、评估和导出模型，使用本地 CPU，没有付费 API 或 GPT-6 调用。

**结果：知识库驱动的零患者训练诊断已有前人工作，不能作为我们的算法首创。新增五个数据集后，未找到在全部题目上普遍接近满分的轻量方法。找到了一个可继续检验的用途：小模型在部分高置信度病例上回答，其余弃答。DXY 上 60/104 例被接受，58 例正确；独立运行的模型 JSON 仅 7,280 字节。**

## 1. “别人是否做过”的明确回答

| 层次 | 查重结论 | 原始来源 |
|---|---|---|
| 根据疾病与表现的集合关系做诊断 | 已有长期研究；多病集合覆盖与我们单病集合求交并非完全同一算法，但基础思想不能称首创 | [Reggia、Nau、Wang，1983](https://doi.org/10.1016/S0020-7373(83)80065-0) |
| 直接利用疾病知识网络，不先训练患者分类器 | 已明确做过；2021 方法直接用 QMR 网络进行贝叶斯诊断与问诊 | [Guan、Baral，2021](https://arxiv.org/abs/2110.08393) |
| 在 DDxPlus 中比较上述方法家族 | 2024 TPKA 论文已纳入 BED，说明需要针对 DDxPlus 调整；其输入为最多 30 轮交互，不等于我们的完整记录目录审计 | [TPKA，2024，§4.1](https://www.mdpi.com/1099-4300/26/9/740) |
| 我们的 92.47% 唯一覆盖、短证明分布与同问题挑战 | 本轮未找到完全相同的定量报告；只能保留为具体实证贡献候选，不能据“没搜到”宣称全球首次 | [本地逐例结果](../23_ddx_generator_audit/RESULTS.md) |

2021 工作需要区分两个分支：SymCAT/HPO 使用已有知识网络；Muzhi/Dxy 从训练集统计建立网络，所以后者并非零患者数据。作者仓库注明数据需向作者索取，本轮未获得 SymCAT/HPO 数据，也未冒充完成复现。[作者代码](https://github.com/hguan6/differential_diagnosis)

本轮检索包括 `DDXPlus training-free`、`DDXPlus set intersection`、`DDXPlus support intersection`、`DDXPlus compatibility metadata`、`DDXPlus exclusive evidence`，以及知识库诊断的历史文献。原始论文与作者代码优先。新颖性是有边界的查重结果，不是穷尽证明。

## 2. 新增数据与实验设计

中文问诊数据来自 [DxFormer 作者仓库](https://github.com/lemuria-wchen/DxFormer)，固定 commit `0e56c10518fe62aed38c96c2e67b9564d8269e70`。直接使用作者发布的 JSON 划分：

| 数据 | 训练 | 最终评估 | 任务 |
|---|---:|---:|---|
| DXY | 423 | 104 | 5 类；中文问诊记录衍生的结构化诊断 |
| MZ-4 | 1,388 | 345 | 4 类；作者发布的这一版本，不是原始 568/142 版本 |
| MZ-10 | 3,305 | 811 | 10 类；中文问诊记录衍生的结构化诊断 |
| MedQA | 10,178，另有 dev 1,272 | test 1,273 | 英文医学考试四选一 |
| MedMCQA 单选子集 | 拟合 108,716；另留 2,000 题选参数 | validation 单选 2,816 | 医学考试四选一 |

MZ-4、MZ-10 属于相关数据系列，不能算两个完全独立临床来源；这些诊断任务疾病类别少、以儿科为主。全部使用结构化字段，不包含从自然语言准确提取症状的难度。MedMCQA 原始 train 共 182,822 条，其中 `single` 120,765；validation 共 4,183，其中 `single` 2,816。本轮排除 `multi`。从单选训练题按规范化问题文本哈希留出约 10% 的组，固定取其中 2,000 题选参数，其他留出题不用于训练。

中文数据在训练划分内进行 5 折 `StratifiedGroupKFold`，相同完整症状与取值向量放入同组；每折独立拟合词典。比较逻辑回归、线性 SVM、RBF SVM、Bernoulli 朴素贝叶斯和 ExtraTrees，共 12 个预设配置。每种输入视图按交叉验证准确率选配置，再评估官方 test。输入只使用症状字段及其状态，不使用病例 ID 或标签。

MedQA/MedMCQA 使用轻量词法检索：TF-IDF 检索已标注训练题，把邻题正确答案文本与当前四个选项做字符 TF-IDF 匹配，按相似度加权。邻居数从 1、5、20 中用开发集选择，两者均选 20。题目解释字段不进入模型。该方法需要训练题知识，不能称零训练知识库方法。

实验前记录的[协议](../../protocol/LIGHTWEIGHT_MULTIDATASET.json) · [下载来源与哈希](../../data/lightweight_multidataset/sources.json)。数据集搜索连接器当前不可用，本轮使用作者 GitHub；考试题沿用工作区已保存的数据及来源记录。[MedQA 来源记录](../../data/external_medqa/provenance.json)

## 3. 全部病例都回答时的实际结果

下表诊断任务统一使用全部已记录字段及回答值，包括显式与隐式资料。这不是主动问诊算法的准确率。

| 数据 | 训练内选出的模型 | 正确率 | 排除与训练重复输入后的正确率 | 压缩模型/索引文件大小 |
|---|---|---:|---:|---:|
| DXY | Bernoulli NB，alpha=0.1 | **81.73%**，85/104 | 81.32%，74/91 | 2.84 KB |
| MZ-4 | ExtraTrees，200 棵树 | **74.49%**，257/345 | 74.47%，245/329 | 1.83 MB |
| MZ-10 | 逻辑回归，C=0.1 | **65.60%**，532/811 | 64.54%，486/753 | 54.91 KB |
| MedQA | TF-IDF + 答案文本匹配，20 邻居 | **36.14%**，460/1,273 | 36.14%，无精确问题重复 | 12.52 MB |
| MedMCQA 单选子集 | 同上 | **42.58%**，1,199/2,816 | 42.57%，2,814 题 | 28.39 MB |

大小使用十进制 KB/MB，包含压缩模型和词典或检索索引，不包括 Python/库运行时，也不等于峰值内存。检索索引比小型分类器大得多，但无需大语言模型。

DXY NB 本机热运行单病例中位时间约 **0.20 ms**，MZ-10 逻辑回归约 **0.11 ms**，包含字典向量化，不含磁盘加载、输入 JSON 解析或自然语言提取。MedQA 全部 1,273 题检索打分约 1.73 秒；MedMCQA 2,816 题约 7.10 秒。硬件、缓存及批量规模影响速度，未做与 GPT-6 的延迟对照。

额外控制：

| 输入视图 | DXY | MZ-4 | MZ-10 |
|---|---:|---:|---:|
| 全部问题身份，不保留回答状态 | 79.81% | 76.52% | 64.12% |
| 全部问题身份及回答状态 | 81.73% | 74.49% | 65.60% |
| 仅显式资料及回答状态 | 67.31% | 67.25% | 52.16% |
| 删除与标签名称直接相同的字段，再保留回答状态 | 81.73% | 71.59% | 59.93% |

各视图独立按训练 CV 选择模型，不能把差值全归为单一特征的因果效应。MZ-4 只看身份的 SVM 比含回答值的所选树模型略高，说明不能预设回答值必然提升这个小样本任务。直接命名字段删除包含“腹泻”“咳嗽”等本来也合理的症状词，只是输入敏感性检验，不证明这些词都是标签泄漏。

再去重训练病例、保留标签冲突后，三个全资料模型在不重复的 test 子集上分别为 79.12%、74.16%、64.28%。重复输入不是 DDxPlus 与本轮结果差距的全部原因。所有配置的 CV 分数、逐例预测和去重结果已保存，没有按最高 test 分数挑模型。

## 4. 弃答方案：准确率与覆盖率一起报告

这是看到首轮结果后开展的探索性跟进。另将原始训练划分按事实向量分组，约 80% 用于拟合、20% 用于校准。只比较固定 C=1 逻辑回归和 alpha=1 NB，在校准集上选择“至少回答 20 例、经验正确率至少 95%”的最大覆盖阈值；随后固定模型和阈值评估 test。

| 数据 | 回答数/总数 | 覆盖率 | 回答部分正确率 | 95% Wilson 区间 |
|---|---:|---:|---:|---:|
| DXY | 60/104 | **57.69%** | **58/60 = 96.67%** | 88.64%–99.08% |
| MZ-4 | 68/345 | 19.71% | 63/68 = 92.65% | 83.91%–96.82% |
| MZ-10 | 150/811 | 18.50% | 140/150 = 93.33% | 88.16%–96.34% |

排除与原始训练划分重复的输入，DXY 回答 49/91、答对 48；MZ-4 回答 67/329、答对 62；MZ-10 回答 127/753、答对 118。

校准集 95% 是一个经验选阈值规则，不能保证最终人群正确率达到 95%；两个 MZ 结果就没有达到。区间仅作有限样本描述，未覆盖阈值选择、数据分布变化等全部不确定性。剩余病例均弃答，本轮没有调用大模型接管，故未测得“小模型 + GPT-6”系统的整体准确率、费用或节省比例。

可执行交付：把 NB 与逻辑回归参数转换成统一的线性分数与 softmax，用 Python 标准库即可运行，保留原来的弃答阈值。

| 模型 | 无依赖 JSON 大小 | 数值核验 |
|---|---:|---|
| [DXY](dxy_portable.json) | **7,280 字节** | 104 例预测和弃答结果全部一致 |
| [MZ-4](mz4_portable.json) | 33,190 字节 | 345 例全部一致 |
| [MZ-10](mz10_portable.json) | 132,529 字节 | 811 例全部一致 |

最大置信度误差小于 2×10⁻¹⁵。[导出核验](portable_verification.json)

```bash
python3 MedicalBeliefStudy/src/lightweight_diagnosis.py \
  --model MedicalBeliefStudy/results/24_lightweight_multidataset/dxy_portable.json \
  --input MedicalBeliefStudy/results/24_lightweight_multidataset/example_findings.json
```

输入必须是数据集的规范化中文字段名及 0/1/2 状态。这里没有自由文本症状提取、开放病种识别或临床部署验证。

## 5. 跨数据集迁移

固定 C=1 逻辑回归，只用源数据集训练，限制为双方已有的共同标签，不做目标数据调参：

| 训练 → 评估 | 共同疾病数 | 目标病例数 | 准确率 |
|---|---:|---:|---:|
| MZ-4 → MZ-10 | 4 | 408 | 66.42% |
| MZ-10 → MZ-4 | 4 | 345 | 69.57% |
| DXY → MZ-4 | 2 | 181 | 78.45% |
| MZ-4 → DXY | 2 | 44 | 90.91% |

最后一行只有两类、44 例，不能拿 90.91% 冒充开放医疗诊断成绩。MZ 两版本也非独立来源；移除源训练精确重复后，前两项为 66.67% / 69.64%。字段命名差异明显，两个 DXY/MZ 方向分别有约 81% / 55% 的目标字段出现次数在源词表之外。跨来源规范化是可继续检验的方向，本轮没有人工建立医学同义词映射。

## 6. 与 GPT-6 比较：已准备什么，缺少什么

当前进程没有可用的 OpenAI/Azure API 凭据，也没有取得同题 GPT-6 逐例结果；本轮 **GPT-6 调用次数为零**。[官方 GPT-6 报告](https://openai.com/index/gpt-6-astra/)中的 HealthBench 等分数对应不同任务，不能与这里的 5 类诊断或考试题子集直接比较。

已为五个数据集输出无标签的 `*_gpt_inputs.jsonl`，给候选疾病/选项及与小模型一致的已记录资料；金标和小模型预测保存在单独文件中。后续对照应固定具体模型版本、提示、输出格式、全部输入、评分规则，报告逐例配对差异、费用、延迟、弃答覆盖率，并针对重复与标签命名线索分别分析。不能用当前对话中的人工答题补作盲测，因为上下文已暴露结果。

当前最直接的结论是：轻量专科分类和选择性回答存在实用空间；“非常轻量且在广泛医疗任务上达到 GPT-6 水平”尚未得到证据。要推进后一目标，需要检验更好的医学知识表示与跨来源语义匹配，随后做同题模型对照，而非只扩大同一种模拟数据。
