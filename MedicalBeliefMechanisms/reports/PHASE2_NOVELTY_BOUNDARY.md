# 阶段2线索的新颖性边界

2026-11-18补查。这是围绕本轮实际出现的“局部数字说明、证据来源混淆、内部读出”的定向排查，读取了论文摘要、官方论文页面及相关检索材料；不是穷尽性系统综述，也不据此声称某项机制从未被研究。

**本轮不能把“加了信息以后答错”“把别人的报告用于当前病人”“某个属性能从内部读出”单独当成创新。**

| 已有工作 | 已覆盖的内容 | 对本轮解释的约束 |
|---|---|---|
| [Shi等，Large Language Models Can Be Easily Distracted by Irrelevant Context，2023](https://arxiv.org/abs/2302.00093) | 在数学问题中加入无关信息，研究推理表现下降与缓解方法 | “额外文字让判断变坏”本身不是新现象；本轮需要区分证据资格与一般干扰 |
| [Yang等，How Is LLM Reasoning Distracted by Irrelevant Context?，EMNLP 2025](https://aclanthology.org/2025.emnlp-main.674/) | 用受控推理图构造干扰，分析路径选择、计算及训练改善 | 受控合成与配对设计本身也不是贡献，必须有新的机制解释 |
| [Niu等，Llama See, Llama Do，ACL 2025](https://aclanthology.org/2025.acl-long.791/) | 研究上下文里出现过的词元更容易被输出，并通过注意力头消融分析这种效应 | 本轮数字说明包含与选项相近的结论措辞；措辞复用是必须排除的竞争解释，不能直接归因为医学信念 |
| [Yan等，LLM Sensitivity Evaluation Framework for Clinical Diagnosis，COLING 2025](https://aclanthology.org/2025.coling-main.207/) | 改变关键医学信息，评估诊断判断是否对这些变化敏感 | “模型没有按关键医学信息变化而更新”已经是已有研究问题 |
| [Ma与Zhang，Retrieval-Induced Mirage，Findings IJCNLP-AACL 2026](https://aclanthology.org/2026.findings-aacl.108/) | 在缺失患者模态时研究医学视觉语言模型把检索到的他人病例当作当前患者观察，并评测来源归属和来源提示 | “使用其他患者的证据”存在直接相邻工作，不能宣称首次发现来源错配 |

这些论文的任务、模型和干预不等同于本项目。表中的“对本轮约束”是基于现有描述作出的研究判断，不表示已证明两项工作完全同题，也不表示本轮错误由其中任何一种既有机制导致。

我们的医学信念主问题仍是：**先前形成的判断是否改变证据的审查和使用；这类变化是否能由超出答案类别的内部状态预测，并通过干预得到解释。** 当前实验只能按实际证据支持其中一部分。若没有稳定的历史效应，不能把一般规则错误、文字干扰或读出工具的失败包装成该主问题已经解决。

对本轮最具体的数字说明线索，后续至少要区分：

- 说明里的结论措辞是否直接增加了某个选项的吸引力；
- 是否只发生在“条件不满足”与“无资格判断”容易混淆的任务；
- 是否与模型实际先前判断有关，还是没有任何旧判断也会出现；
- 是否在新病例、不同医学规则、不同模型中复现；
- 候选内部信息是否对该行为有选择性因果作用。

这是一份避免过早定题的边界记录。不能把“本轮没有找到完全同题文章”写成首创证明；等具体机制有足够结果后，还需针对该机制阅读全文和追溯引用。
