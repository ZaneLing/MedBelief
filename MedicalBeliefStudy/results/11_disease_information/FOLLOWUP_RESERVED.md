# 保留发现：简单分类器与记录结构

本方向按研究讨论单独保留，不作为当前“医学信念更新”论文已经成立的重大创新，也不因高准确率就停止内部机制研究。

## 已有结果

旧120例、24类、五折病例隔离：完整文字120/120，仅问题文字120/120，仅证据ID117/120。每折96例训练、24例测试。

## 本轮独立划分复核

用上述旧120例训练，在新选DDxPlus test split的120例测试：

| 输入 | 正确数 |
|---|---:|
| 问题与答案文字，TF-IDF+线性分类 | 120/120 |
| 只有问题文字，TF-IDF+线性分类 | 119/120 |
| 证据ID及取值的稀疏特征，线性分类 | 120/120 |
| 仅哪些证据ID已记录，线性分类 | 120/120 |

两批病例无完全相同的证据事实集合。两批仍来自同一个模拟数据来源，不能称外部临床验证；预训练是否接触过公开数据尚未检验。这里训练的是分类器，非“无需训练”。未进行实际速度/显存基准，也未部署截断大模型。

这个复核说明高可分性不限于最初120例的五折划分。对诊断方法的价值与跨来源泛化，作为独立研究分支保留。

## 2026-11-19：扩大到全部49类

已完成[134,529例官方测试集的扩大验证](../22_ddx_classifier_expansion/RESULTS.md)：问题文字Ridge 98.23%；证据出现位置逻辑回归99.18%；保留答案值逻辑回归99.67%。排除训练集中相同事实组合后分别为98.03%、99.09%、99.64%。同时找到340种问题集合对应不同疾病。原始120/120已再次复现，但不是对所有病例唯一可识别的保证；这个分支的代码、病例、模型、逐例结果与已有研究对照均已保存。
