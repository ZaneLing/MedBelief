# 医学信念如何随证据改变：统一研究设计

版本：2026-11-18。本文区分已完成测量与下一阶段设计；新增内容未自动成为既有实验结果。研究对象是模型对疾病的内部表征与判断如何随证据更新，不是构建诊断排行榜。

## 1. 论文问题与分析单位

核心问题：同一患者的新证据进入模型后，模型如何重新分配对不同疾病的支持？这个变化在哪里出现，经过哪些计算被加强、保留或覆盖，最后如何成为诊断？

研究链条：证据进入 → 信息被关注和整合 → 疾病表征变化 → 模块推动或阻碍变化 → 最终判断。每个环节同时研究正确更新、错误转向、保持不变和不确定性，不能预先规定所有更新都应当接近最终标签。

最小观察单位：病例 × 已揭示证据集合 × 呈现顺序 × 回答格式 × 模型。每次前向计算进一步展开为层、模块、注意力头和位置。病例为独立统计单位；轮数、层数、头数不是新增患者样本。

## 2. 当前到底测了什么

当前模型是冻结的 Qwen3-1.7B：28 层，隐藏维度 2048，每层 16 个查询注意力头、8 个键值头。FP16 本地推理，无训练。

样本为 DDxPlus 模拟病例：12 例初始探索、60 例新增独立复现；另有 180 例仅用于读出训练与开发。6600 条模型观测包含重复顺序、编码和时间点，不等于 6600 个患者。

候选固定为肺炎、支气管炎、哮喘急性发作、肺栓塞、自发性气胸、急性肺水肿。这是预选疾病的比较实验，还不是全科诊断。

每轮给出年龄、性别和截至当轮的全部已揭示证据，在 `Diagnosis code:` 后直接读取 A—F 对应 token 的原始分数。设疾病 d 对应分数为 z(d)，则：

`q(d) = exp(z(d)) / Σ候选 exp(z)`

q 是“这六个候选之间的相对支持”，不是患者真实患病概率，也不是模型自己说出来的百分比。唯一最大值为当轮首选；并列单列处理。另存完整词表上的候选总概率和全词表实际首 token，检查模型是否本来想输出别的内容。

每轮都重新输入累计事实，不加入前轮回答，不保留对话状态。因此现有轨迹反映证据输入变化后的模型计算；尚未测量先前诊断承诺对后续判断的影响。

| 测量项 | 当前状态 | 可回答的问题 |
|---|---|---|
| 逐轮最终疾病分数、排名、转移 | 已完成 | 倾向哪种病，新增证据后如何改变 |
| 28 层的隐藏状态 | 已完成，位于诊断输出锚点 | 生成答案前，各层状态怎样变化 |
| 每层进入、注意力增量、注意力后、MLP 增量、离层状态 | 已完成，每处 2048 维 | 哪类计算改变了状态 |
| 每层原始输出头读出 | 已完成 | 用最终输出规则投影该层时，会偏向哪种病 |
| 独立训练的读出校正 | 已完成部分方法 | 原始层间分歧是否来自读出失真 |
| 模块替换干预 | 已完成最后层及部分晚层实验 | 改变内部计算能否改变最终判断 |
| 每个头对每条证据的注意力权重 | 尚未提取 | 模型计算时将注意力分配到哪些信息 |
| 全部证据位置的逐层状态、每头输出、MLP 神经元激活 | 尚未系统提取 | 疾病信息在哪里出现、如何流向答案 |
| 无候选自由诊断、多轮回答历史、不同规模模型 | 尚未系统完成 | 结论能否跨任务设置和模型规模成立 |

注意力模块的输出增量不等于注意力权重矩阵。推理过程中模型参数不变，变化的是激活、注意力分配和输出分布。

## 3. Ground truth：必须保留三种不同的参照

### 3.1 最终疾病标签

DDxPlus 的 `PATHOLOGY` 是模拟患者的疾病标签；不得放进模型输入。当前 252 个病例的私有标签均与原始 CSV 一致。

新增 60 例、基础证据顺序下，单一编码最终命中标签 34/60；将六种编码的疾病支持对齐后取平均，再选首位，命中 37/60。它们回答限定六候选任务的标签命中情况。

### 3.2 完整病例的参考鉴别诊断

原始数据同时提供 `DIFFERENTIAL_DIAGNOSIS`，包含候选病及其参考概率。它和单个最终疾病标签作用不同；它是数据集的参考，而非经过本研究验证的真实患者概率。

本次源数据审计结果：

| 队列 | 病例数 | 标签与原始数据一致 | 标签也是参考分布最大值 | 现有六疾病覆盖的参考概率，病例平均 |
|---|---:|---:|---:|---:|
| 新增复现 | 60 | 60 | 36 | 26.08% |
| 初始探索 | 12 | 12 | 8 | 24.94% |
| 读出训练 | 120 | 120 | 77 | 25.53% |
| 读出开发 | 60 | 60 | 41 | 25.84% |

这说明最终标签与“参考分布中最可能的病”不能混用；六疾病归一化也忽略了大量候选外参考概率。26.08% 是六病在数据集参考分布中的覆盖率，不是模型准确率。

审计来源：[ground_truth_audit.json](ground_truth_audit.json)；复现脚本：[audit_ground_truth.py](../src/audit_ground_truth.py)。原始参考字段在本次审计前未成为现有主要评估指标。

下一版同时报告标签命中、标签排名、对参考鉴别诊断的分布距离及参考集合覆盖。只在相同疾病空间比较分布。若仅比较组内候选，则同时报告参考覆盖率和组内条件分布；不能把截断后的条件分布称为完整参考分布。

### 3.3 每轮应有的判断

当前数据不提供每个证据前缀的标准后验概率。最终疾病是肺炎，并不意味着第一轮模型就应选肺炎，也不意味着肺炎支持必须每轮递增。

因此“正确→错误”在当前报告中只表示从命中最终标签变为不命中，不能直接解释为不合理更新。判断一次更新是否合理，还要看当轮实际可见证据及其区分力。

后续分两条轨道：

1. **自然病例轨道**：保存原始标签、参考鉴别诊断、明确可见证据和来源。检查文本转换遗漏、默认值、单位及量表；不把未记录项改写成阴性。根据独立于被测模型的资料，记录哪些证据有明确方向依据；无法确定方向的更新只做描述。
2. **可计算参照轨道**：另建明确联合生成规则的受控任务，计算每个证据前缀的精确参考分布，用于检验更新过程。相关证据按联合分布处理，不能将重复症状当作独立证据相乘。该轨道验证计算机制，不冒充真实临床概率。

对于自然病例，“全部记录已展示”与“证据足以唯一诊断”分别标记。涉及指南的证据方向只采用明确适用人群、版本与条件的原文依据；指南不自动提供逐轮数值后验。任何由最终诊断倒推添加的线索不能混入原始病例主分析。

## 4. 如何统一不同疾病、不同病例

### 4.1 先按鉴别诊断场景，再按疾病与科室

主分组是“相近表现下需要区分的一组疾病”，如呼吸困难相关、胸痛相关、腹痛相关、发热相关、头痛或神经症状相关。具体组数和疾病表由数据覆盖审计决定，不能声称当前已覆盖这些组。科室作为交叉标签，因为同一表现可以涉及多个科室。

组内候选表在看模型结果之前固定，对该组全部病例相同，不按每个病例的答案添加正确选项。跨组重叠病例按预先确定的主场景归属进入总汇总，其他标签用于分层，避免重复计数。

下一版设置两种任务：固定鉴别组用于细致机制分析；全 49 病种的同一候选空间用于完整参考分布比较。全病种任务先验证答案编码及名称长度效应，再扩展。两种任务分别报告；更改候选数量后不直接比较原始 q 大小。自由诊断作为独立输出控制，保留无法映射和候选外答案。

### 4.2 对齐疾病“角色”，保留具体疾病身份

每例同时保存具体疾病轨迹与角色轨迹：最终标签病、上一轮首选病、当前最强非标签病、参考分布首位病。最强非标签病可能更换，必须记录身份，不能将不同病的概率无说明地连成同一条曲线。

| 指标 | 直白含义 | 主要使用位置 |
|---|---|---|
| 最终标签命中率、排名 | 最后有没有找对，正确病排第几 | 终点 |
| 标签病与最强竞争病的分数差 | 正确病领先或落后多少 | 各轮、各层 |
| 同一疾病对的 log-odds 变化 | 新证据把天平推向了哪一边 | 相邻轮；疾病对在比较内固定 |
| 分布变化大小，JS | 这轮改了多少主意 | 各轮；另报变化方向 |
| 错到对、对到错、错病之间切换 | 转移属于哪一类 | 轨迹、转移矩阵 |
| 首次命中与持续命中时点 | 什么时候找到标签病，之后是否守住 | 轨迹；未持续命中的单列 |
| 最终标签 NLL/Brier，参考分布 JS | 自信程度与标签、参考分布是否相符 | 终点；不把早期高熵自动算错 |
| 同事实顺序、格式敏感性 | 内容不变时，判断是否仍变 | 病例内配对 |
| 干预后的分数差变化 | 某个内部计算对诊断有多大实际作用 | 因果实验 |

“没有切换”也可能伴随大幅概率变化，故首选和完整分布都保留。疾病分数取连续值，唯一首选与并列分开。

每例先汇总，再按疾病、场景做等权平均；同时保留原始病例加权结果。置信区间按病例或病例配对重采样，不按数千个层/轮观测重采样。训练、开发、最终检验按患者及重复病例簇隔离。

不同病例的第 3 轮并不等价。图中同时使用原始轮次、证据揭示比例及预先标记的证据事件对齐；揭示比例仅用于展示，不代表等量医学信息。总图显示各位置样本数，短病例不靠填充制造后续观测。

## 5. 从表面到内部：四级证据

### 一级：它最终偏向什么

每轮保留候选分数、完整词表候选总概率、首位与第二位、标签排名、熵，以及疾病名序列评分。编码轮换后先还原疾病身份再平均。主结果同时显示格式变动范围，不能只挑最稳定或最好的一种编码。

输出：病例疾病支持曲线、跨病例转移矩阵、终点正确率及顺序敏感性图。

### 二级：疾病信息在哪里可以被读出

保留每层诊断锚点状态，新增每条证据末尾、证据边界和汇总位置的状态。自回归模型中较早位置无法看到后来证据，因此证据 token 的状态与最终诊断锚点不能当作等价的全病例表示。

两种读出目标必须分开：

- **判断读出**：从某层预测同一轮模型最终的疾病分布，回答“它准备怎样作答”。
- **疾病标签读出**：从某层预测数据标签，回答“这里是否有可用于区分真实疾病的信息”。只能在独立患者上评估，并控制证据量、候选编码、疾病词直接出现与简单输入特征。

原始输出头投影与训练读出并列，训练读出使用患者隔离的训练/开发集；最终检验集不得用于选择层、正则或训练轮数。加入常数、标签打乱、词面特征等基线。读出器能读到信息，不等于模型实际用它作答。

当前仿射读出训练目标是最终模型分布，因此它降低中间层与最终层的分歧，不能单独证明各层具有相同医学判断。原始投影也不能直接命名为每层真实疾病概率。

输出：横轴证据轮次、纵轴模型层、颜色为标签病相对竞争病的支持差；另图显示读出可靠性。总图按病例配对汇总，原始个案图用于解释而非替代统计。

### 三级：证据怎样进入计算

新增诊断锚点到各输入 token 的逐层逐头注意力权重，并按证据组聚合。保存完整 token 归属：系统提示、候选疾病、人口资料、各证据、模板与回答历史。模型可能关注候选词或格式，因此不能只画医学证据并将其重新归一化到 100%。

每组同时报告注意力总质量、每 token 平均值、组长度和位置，避免长证据天然占优。记录 Q/K 及必要的 V/头输出用于重建和干预；核对 RoPE、分组键值头和因果遮罩。优先保存诊断锚点到所有 token 的行，完整 token×token 矩阵仅在预先抽样的病例中保存，以控制存储。

每层保存注意力分支与 MLP 分支增量；深描子集保存逐头输出、MLP 门控/中间激活及其到最终读出的影响。激活很大不自动意味着更重要，单个神经元不未经验证就命名为“肺炎神经元”。

新增记录功能必须先与原生前向计算逐项核对：最终 logits、首选、归一化、张量形状和位置一致。实现显式注意力时，核对其与原有融合计算的数值差，不能因换实现而产生现象。

输出：层×证据组注意力图、模块导致的分数差变化图、典型病例的信息流图。注意力用于定位候选计算；是否真正影响诊断由下一步检验。

### 四级：改变哪里，诊断才会改变

针对发现集定位的层/头/模块，在新病例上冻结位置和假设做验证：

1. 配对病例只改变明确的一组证据，或使用相同病例的相邻证据前缀。
2. 将该证据对应的内部状态、头输出或模块增量替换为配对来源，并继续前向计算。
3. 测量最终疾病分数差、标签排名和完整分布改变，而不只数首选是否翻转。
4. 同步做原位自身替换、匹配范数的方向扰动、无关位置/模块和非医学文本控制；记录候选总概率及干预是否造成输出异常。
5. 逐层、逐头发现使用多重比较控制；确定候选后在未参与筛选的病例复验。选择性消融后恢复原输出的双向干预优先于单次大幅破坏。

新旧前缀拼接内部状态可能产生模型平时不遇到的组合；因此跨轮替换与更自然的证据配对替换相互验证。模块替换成功只定位该设置下的计算作用，还要通过跨疾病、格式及非医学同结构任务检查其医学特异性。

## 6. 证据顺序、回答历史与模型规模

保持两条独立轴：

- **资料排列**：相同事实集合，只换文本顺序；终点或相同事实子集作配对。不同事实集合的中间轮不称为纯顺序效应。
- **先前判断**：事实相同，分别不给前轮答案、提供模型自己的前轮答案、提供受控的正确/错误先前判断。匹配长度并加入中性历史控制，检验先前判断是否改变证据处理。受控注入和自发错误分别报告。

先完成 1.7B 的测量验证及独立病例复验，再扩展同系列模型规模。使用一致证据、格式、评分与精度策略；将层位置按相对深度展示，同时保留实际层号。不同模型的隐藏维度和第 k 层不默认同义，不直接比较向量坐标；优先比较疾病分数、读出性能和因果效应。

## 7. 阶段交付与预先确定的判断标准

| 阶段 | 工作 | 交付与进入下一步的条件 |
|---|---|---|
| A 数据与答案空间修正 | 保留完整参考分布，核对文本转换，建立场景与固定候选；独立留出患者 | 数据审计、候选覆盖表、冻结的主指标。当前审计已完成，任务扩展尚未运行 |
| B 统一逐轮轨迹 | 1.7B 上扩展场景与病例；先跑计时小批次再确定规模；每个场景/疾病都有独立病例 | 完整概率与转移总表；同事实顺序/格式对照；以全病例分布判断是否为普遍现象 |
| C 全层与注意力测量 | 全病例捕获诊断锚点；按预先分层随机抽样做全 token/头/MLP 深描 | 原生一致性检查通过，读出优于相应基线，注意力及内部变化总图 |
| D 因果验证 | 在发现集定位，在新病例冻结检验；覆盖正确更新、错误转向与不变三类 | 配对效应量、区间、控制实验。没有效应同样记录，不只发表翻转个案 |
| E 广度检验 | 跨场景、候选空间、回答历史、非医学同结构任务，再到更大模型 | 区分一般信息处理机制与医学任务特征，形成论文总体结论 |

样本量按病例级主要效应精度设计，利用现有病例估算方差，不按“看到显著就停止”决定。新的确认性检验病例不得用于修改假设；失败后新方法另立版本与独立检验集。当前不承诺尚未计时和完成抽样审计的总病例数。

## 8. 数据产物与论文主图

统一输出两张主要长表：

1. `case × round × order × format × layer × disease`：疾病分数、标签与参考信息、读出方法、唯一首选/并列、阶段状态及来源哈希。
2. `case × round × layer × head × evidence_group`：注意力总质量、每 token 平均、位置长度、头输出统计及干预效应。

模块/神经元原始张量另存压缩二进制并索引，避免将所有特征强行塞入一个大表。每次运行冻结模型权重哈希、数据版本、模板、随机种子、数值精度和采集实现。

- 图 2：所有病例的轨迹类型、标签与参考分布表现，给出发生比例与区间。
- 图 3：证据轮次×模型深度的总体变化图，区分原始读出与独立读出。
- 图 4：证据被关注、进入状态、影响输出的对应关系。
- 图 5：内部替换的配对因果效应及控制。
- 图 6：跨场景、顺序、历史与模型规模的稳定性。

论文结论按证据递进：发生了什么 → 内部哪里出现 → 哪种计算使其发生 → 在什么条件下成立。若内部测量不可靠，就修复测量；若机制没有跨病例成立，就报告适用条件，而不是将个案包装为总体规律。
