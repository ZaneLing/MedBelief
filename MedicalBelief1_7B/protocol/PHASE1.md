# 第一阶段：直接诊断与逐层捕捉

在推理开始前确定。本轮按用户要求由 4B 改为 Qwen3-1.7B，28 层、2048 维，使用本地原始 BF16 权重转 FP16，模型参数不训练。

1. 主条件：冻结的 12 例、131 前缀，D 模式，不生成思考，不把前轮答案带到下一轮。每个前缀先前向一次，捕捉每层的 r_pre、attn_delta、r_mid、mlp_delta、r_post。
2. 每层对 r_pre、r_mid、r_post 分别用模型最终 norm 和共享输出头投影，保存候选原始分数、全词表代码概率、六类相对支持、候选总概率。未训练读出，因此称为原始输出头读出。
3. 保存最后一层完整词表 logits。额外用无约束 greedy 生成最多 32 个词元，遇模型 EOS 停止；只解析严格的一字母回答，不把条件概率第一名冒充实际文本回答。
4. 对三个预定病例 0857360、0875644、0868644 的首轮、中间轮、末轮，做六种循环选项映射。9 个点已属于主条件，因此另加 45 点，共 176 个观察点。对照既改变字母映射，也改变候选在列表的位置，不能据此拆分两种效应。
5. 同样的 9 个主条件点，核对采集前向与正常完整模型前向：全词表 logits 的 atol=rtol=1e-3，argmax 一致。每个观察点核对残差重建、末层读出、概率归一化和词元边界。
6. 以病例为单位报告最终选择、第一次正确、稳定正确、回退次数，以及每组证据引起的变化。全部 12 例都展示；不筛掉模型答错的病例。
7. 模块分差使用固定的两个疾病比较，表示读出分数的变化；不称为因果效应。当前不重建注意力权重，也不宣称权重随证据改变。
8. 原始病例来自模拟数据，真值为数据源标签。逐轮揭示不是临床就诊时间线。早期资料不足时，偏离最终标签不自动等于不合理。

冻结源码和输入哈希写入每个 run。若代码或协议改变，使用新的 run ID。每个观察点原子写入，支持相同配置的中断续跑。模型文件在运行前后校验哈希。本阶段收费模型 API 支出为 0。
