# 阶段20：默认诊断来自什么？

在新增条件推理前冻结的探索性最后一组追踪。固定问卷使85/120选择COPD相关诊断，而该疾病位于原候选列表首位。需要区分候选位置与问卷诱导的输出偏向，不预设哪个解释成立。

对全部预定24例终点，新增四条件（共96次1.7B观测）：

- empty_panel：保留年龄性别、全部223问题和49候选，所有患者答案Unknown。
- empty_append：同样年龄性别与49候选，不给任何症状/病史，也不放问卷问题列表。
- reverse_candidates：完整患者事实与固定问卷保持，仅反转49候选的呈现顺序。
- rotate_candidates：完整事实保持，仅将候选表固定循环移动16项。

候选评分统一还原到原49疾病顺序；实际呈现顺序另存。保留贪心续写、规范病名全序列分数、28层状态。没有患者证据的条件只描述输出偏向，不计算诊断正确率。候选反转/轮换条件仍有相同完整病例事实，可报告标签命中与首选变化。

主要判断：若换列表后输出仍集中同一个疾病，不能仅用“选第一项”解释；若空问卷较无问题列表更集中某病，说明问卷文本本身参与形成输出偏向。这里的“先验”是没有症状事实时的模型条件输出，不是人群患病率或经校准的贝叶斯先验。所有结论先限于1.7B当前提示。
