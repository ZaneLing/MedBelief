# 疾病方向干预的位置与词元测量补充

在阶段15新增干预开始前记录。主协议与剂量、病例、层位不变。

`all_answer_positions` 实际覆盖诊断锚点及教师强制答案续写的所有位置，包括病名、JSON闭合符与EOS预测；不是只处理病名字母。主评分继续使用完整字符串。另根据分词偏移记录与病名字符区间相交的词元索引，将病名部分和剩余格式/结束符部分的变化分别报告。跨越病名与闭合符边界的词元计入病名，并记录这一分词约定。

第28层锚点干预直接在同一次自然前向的最终隐藏状态上加向量，复用未经改变的KV缓存；这与完整前向后在相同位置加向量等价。第21层重新执行前向，保证后续层与KV确实受到影响。每个方向共享前缀状态，锚点条件与全续写条件独立克隆缓存，避免前一个候选污染下一个候选。

主结果为相对同范数随机方向的疾病对数比变化。外部读出器自身分差增加是干预构造的结果，不计作独立证据。病名部分、同首词元选择性与格式部分用于解释干预究竟作用于哪个计算环节。
