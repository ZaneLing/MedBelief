# 阶段18：已有4B配置的独立模型复核

在4B新增观测开始前冻结。使用项目中已经下载的`Qwen3-4B-8bit`，36层、隐藏维2560、32查询头、8KV头、8-bit权重量化(group size128)，浮点计算转FP16。与1.7B FP16不同，比较是模型配置复核，不识别纯规模因果效应。

不新增患者、不按模型表现选样：旧120例终点作为读出训练，新120例终点为测试；新24例基础顺序全部前缀。固定原追加式提示与49候选完整病名评分。共424次观测，保留36层五处状态、诊断位置各头对证据组注意力、完整病名与逐词元评分和贪心续写。

外部读出采用相同L2归一化、训练中心化与ridge，alpha=.1主分析，.01/1敏感性。报告全部36层，预定9/18/27/36层；与1.7B对应四分位深度而非同一绝对层。24类读出只与同24类模型排序比较。主复核问题：内部信息与输出差距、逐条证据下的大幅变化、输出换病时内部读出是否同步。暂不跨模型直接比较未校准读出分数幅度。

不将4B内部干预写成已完成；本轮疾病方向因果检验仍限定1.7B。模型文件哈希前后核对，API费用0。该模型已有8-bit量化，不能把结果描述成BF16或无量化。
