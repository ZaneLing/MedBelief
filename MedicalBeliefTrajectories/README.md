# 医学信念：随证据逐轮变化的逐层诊断轨迹

2026-11-18方向修订。本文是新研究设计，尚未产生新实验结果。

**我们要研究的是：同一个病人，一条条证据到来时，语言模型各层对不同疾病的支持怎样变化，什么时候接近最终疾病，什么时候偏离，以及哪些内部计算造成转向。**

例如一个最终疾病标注为肺炎的病例：初始材料可能让模型偏向支气管炎；加入几条证据后可能转向肺炎；也可能一度转对，后来又偏向其他疾病。我们要把整个过程量化，而不是只问最后有没有答对。这只是解释研究问题的例子，不是已运行病例或预定结果。

研究的三个坐标：

| 坐标 | 表示什么 |
|---|---|
| 证据轮次 | 已看到0、1、2……最多10组证据 |
| 模型层数 | 从早层到中层、晚层，分别处于什么诊断状态 |
| 候选疾病 | 肺炎、哮喘急性发作、肺栓塞等疾病的相对支持度 |

核心产物是一个“证据轮次 × 模型层 × 疾病”的测量数组，并配上实际输出与最终疾病标签。

## 与之前实验的关系

- `MedicalBeliefMechanisms/`主要测报告可用性、旧判断影响、内部信息能否被读出。它提供了模型加载、状态采集、对照和核验工具，但没有完成上面的逐轮疾病信念测量。原实验作为历史探索保留。
- `ClinicalBelief/`已有逐轮证据、最终疾病标签、49类诊断轨迹等环境基础。但其中多数疾病概率来自外部的朴素贝叶斯、MLP等自建模型，并非语言模型内部；复核见[旧项目审计](../research/clinicalbelief_review_20261117/AUDIT.md)。
- 新方向结合前者的内部采集能力和后者的证据轨迹环境，直接观察开放权重语言模型。

## 一个关键术语

普通推理时，训练得到的模型权重保持不变。随证据变化的是激活、注意力分配和输出分数。我们主要测这些动态状态；注意力分配与参数矩阵不是一回事。

当前实施入口：[医学信念轨迹的测量设计](MEASUREMENT_DESIGN.md)。已经选好12个成人DDxPlus病例，完整展开为131个时间点；完成786种输入排列的选项分词核验及模型接口检查。文档规定了每轮D/R/P测量位置、五阶段内部捕捉、概率公式、函数输入输出、存储和作图要求。尚未运行模型。
