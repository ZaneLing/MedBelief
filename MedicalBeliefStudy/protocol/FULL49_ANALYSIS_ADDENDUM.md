# 阶段06—08统计补充

在阶段08干预输出生成前固定：以病例为统计单位，先平均同一病例两个编码的有效配对。主要检验为旧MLP替换相对固定循环移位对照，在最终分布向前轮靠近的JS量上的差。第26、27、28层分别进行双侧单样本t检验（零均值），三项Holm校正；方向依照原方案检验26/27负向、28正向是否一致。同时提供2000次病例bootstrap区间。层24/25、注意力、分组差异为探索性。

原生自身替换未通过数值检查的前缀×层记录保留，但从干预效应分析排除；输出排除数及有效病例数。分析不以首选发生变化作为连续效应纳入条件；首选恢复只在前轮和当前轮各有唯一且不同首选的子集中报告。

疾病名控制固定为此前选定24例的基础顺序终点：无候选提示，比较49个规范疾病名加EOS的完整序列分数，并以每token平均对长度敏感性作单列分析；另保存不限定候选的贪心诊断。无候选提示将“Compare the listed diagnoses”改为“Assess the current presentation”。完整序列分数、token平均分数与字母分数的含义不同，不把差异全归因于一个token。自由文本的自动匹配仅为规范名严格匹配，未匹配不自动等于医学错误。

新增代码及输出分别存档，不修改已冻结的观测脚本与输入。
