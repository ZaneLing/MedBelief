# 论文主线修订记录

## v0.1 · 2026-11-18：从当前实验建立可更新的全文框架

### 输入证据

阶段01—05的已完成结果；真值与参考鉴别诊断审计；医学信念统一研究设计。

### 当前定位

研究医学证据怎样改变模型内部疾病判断，并最终形成诊断。逐轮行为、内部表示、证据处理与因果作用属于同一条论证线。

### 相对早期故事的调整

1. 原始“最后层压制正确内部判断”的个案不足以作为中心结论：60例中没有跨两种核心编码重复同一疾病转向的实例。
2. 最后层MLP增量的定向干预效应成为当前最明确的机制起点；不同层作用方向相反保留为待独立复验的候选发现。
3. 新增完整参考鉴别诊断和候选覆盖问题：最终标签与参考首位不同，六候选范围不足以代表完整鉴别过程。
4. 顺序和编码对照支撑主结论可信度；论文总体仍锚定医学证据更新。

### 保留开放的问题

是否存在跨表达稳定的疾病内部状态；证据是否在特定计算中被选择或削弱；前轮诊断能否改变后续证据处理；机制如何跨疾病与模型规模成立。

### 本版产物

建立主线、全文结构、证据表和下一步决策文件。本轮仅组织论文论证，没有新增模型推理实验，也没有宣称完成最新相关工作检索。

## v0.3 · 2026-11-18：新增阶段06—11并重写机制解释

新增120例、24病种的完整候选实验，逐头注意力、旧MLP确认、完整疾病名复查、真实疾病五折读出及文本结构审计。所有新数据均来自固定队列，未为制造机制更换病例。

## v0.4 · 2026-11-19：从信息可读走到局部输出作用与诊断边界

新增DDxPlus test 120例，旧120例独立训练读出；两种输入呈现、全部24例证据轨迹、28层状态、定向干预、肯否及呈现分解，并在已有4B 8-bit配置复核。分类器高分分支遵照研究定位单独保留。

主线修改：

1. 固定问卷没有消除全部记录模式线索，但揭示了更清楚的分离：可读性提高，原生诊断反而下降。
2. 撤回“内部信息完全没被使用”的笼统解释。8项疾病方向主对比全部为正，连续自然更新也有正相关，说明疾病相关方向对输出有作用。
3. 将问题推进到“作用是否足以决定诊断”：当前5%剂量没有新增正确诊断，原本错误病例的决策分差明显大于干预带来的变化。
4. 最后层锚点的旧MLP效果经词元分解只涉及首词元；不再把这类效果单独解释为医学概念更新。加入更早层、全部续写位置和共享首词元选择性。
5. 4B配置提高了追加式诊断表现，但固定问卷仍从16/24降至4/24；具体偏向疾病随配置变化，不将COPD偏向写成所有模型共有机制。
6. 以中耳炎病例引入，随后按120例总体、自然更新、内部干预、条件与模型复核组织完整论文，不再用旧肺栓塞单例承担总体证明。

新增[完整论文稿](07_MANUSCRIPT.md)、[测量附录](09_MEASUREMENT_APPENDIX.md)、[机制相关工作补充](08_MECHANISM_RELATED_WORK_ADDENDUM.md)，并保留全部原始记录、病例图谱和失败解释。空问卷与候选顺序的最终数据及其评分对照统一进入阶段20和当前综合报告。
