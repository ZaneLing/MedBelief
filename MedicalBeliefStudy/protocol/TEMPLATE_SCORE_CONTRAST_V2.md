# 空输入分数对照：分析补充

在阶段20模型观测开始前写入，使用已计划的空问卷/空追加提示，无新增模型调用。

对预定24例及append/panel两种输入，固定系数1，计算完整事实病名对数分数减相同年龄性别、相同候选表下的空输入对数分数。对49病重新排序，比较原始与差值排序的来源标签命中、COPD相关选择及病例配对变化。不用测试标签调整系数、选择空输入或挑病例。

这是一项诊断性对照，借鉴已有contextual calibration思想，不提出新算法。差值归一化只用于候选相对比较；它既不是临床后验，也不保证消除一个可分离的纯先验，因为输入事实和背景可能相互作用。若改善或恶化，均报告；不把成功直接解释为模型内部已形成正确临床信念。

方法先例：[Zhao等，Calibrate Before Use，ICML 2021](https://proceedings.mlr.press/v139/zhao21c.html)。此补充属由主结果触发的探索性分析，不替换阶段20原有候选位置及空问卷检验。
