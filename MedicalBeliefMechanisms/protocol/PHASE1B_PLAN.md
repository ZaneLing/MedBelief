# 阶段1B：校准医学信念实验的测量

执行日期：2026-11-18（Asia/Shanghai）。首轮结果保持不变。本轮公开权重本地推理，收费API预算0美元。

目标是得到能区分“医学规则没理解”和“旧判断改变证据处理”的实验条件，不以出现预设异常为通过条件。

先检查原实现的注意力因果掩码、实际分词内容与权重加载；用固定小样本比较不同作答格式、思考模式和参考版本。开发诊断可以据失败修订，但每次修改单独记录。选定条件后冻结新的确认集，才能判断是否通过。

确认标准沿用上一阶段预定门槛：每个医学域总体正确率至少90%，每类答案至少80%，选项轮换后语义一致率至少95%。若选择自由文字作答，必须报告解析成功率并在另一种答案呈现中复核，不把不可解析输出当作正确。门槛只用于工程校准，不是临床安全标准。

最初的生成诊断使用固定四题：原肌酐阴性题、原血栓路径阴性题、同一数值关系的简短逻辑题、一条相反的数值关系。比较原字母选择、直接解释式回答和思考模式。生成文本只用来核对回答与计算，不把文字推理当作内部机制。

参考版本采用Transformers 4.51.3，与原4.57.3隔离安装；相同权重、分词器、精度和提示进行比较。此版本对照仍共享PyTorch，不构成完全独立的软件实现。必要时进一步作手工因果掩码或另一后端对照。

执行补充：新增原生Apple Silicon的MLX后端作为独立实现对照，并评估生成速度。仍读取相同的、已验证SHA256的公开权重，不训练或修改权重。安装版本记录在`mlx_package_selection.json`及后续实际环境清单中。参考：[MLX-LM官方说明](https://github.com/ml-explore/mlx-lm)、[Qwen3官方模型说明](https://huggingface.co/Qwen/Qwen3-1.7B)。后端切换必须先检查分词一致性与配对答案；不能把后端、精度变化当作模型机制。

校准通过后，继续开展医学信念开发实验：当前医学事实固定，比较先前判断来源、证据有效性、支持与反对方向，以及真正依据撤回与无关材料撤回。同步采集内部状态，先做留出读出及控制基线。

按用户2026-11-18补充要求，不设独立医生审核门槛。研究对象是LLM的医学信念，指南与程序标签用于明确实验中的证据及规则真值；不把研究结果外推为临床诊疗验证。

配置排查补充：4B思考配置在冻结确认集出现了把撤回血压报告当成有效资料的错误。完成该配置全部记录后，再以同一冻结材料评估4B非思考、贪心生成配置；保留两种配置的全部结果，不放宽门槛。此补充是在观察到思考配置错误后决定的配置选择，不能用于声称思考模式的因果优劣。如果非思考配置通过，还必须在后续新病例的无旧判断条件检查其适用性。两个配置还同时改变采样方法，任何差异都不能单独归因于思考开关。
